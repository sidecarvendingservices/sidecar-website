# Command Center — v1.10 Spec (superseded — see split docs)

This single-file draft has been superseded after a read-only
accessibility/UX audit found the dashboard's underlying patterns
(always-visible forms, dense tables, an ever-growing Machine Detail
modal, div-based "buttons") wouldn't hold up under the full v1.10
feature list without foundation work first.

**The plan is now split into two releases, each its own doc:**

- **`V1.10.1_SPEC.md`** — Foundation: responsive/overflow fixes,
  accessibility (WCAG 2.2 AA), Machine Detail converted to a proper
  workspace instead of a modal, shared table/form/dialog patterns,
  permissions enforcement mechanism, Metric Dictionary, Data Health &
  Freshness, Activity & Audit History, Command Center Action Center,
  Global Search/Saved Views.
- **`V1.10.2_SPEC.md`** — Features: everything originally scoped in
  this draft (restock workflow, planogram, per-machine pricing, machine
  troubleshooting/remote control, Machines page redesign, expense
  editing, Case Calculator, QMOS edit/delete, negative-backstock
  adjustment, property contracts, batch expiration tracking, QMOS
  pattern detection, Backstock sourcing priority, Demo/Consultation
  Resources, Google Ads CPC/CPA) — built **on top of** the v1.10.1
  foundation, not standalone.

v1.10.2 depends on v1.10.1 shipping first. See those two files for the
actual specs, open questions, and build order — this file is kept only
as a pointer since it can't be removed from the folder.
