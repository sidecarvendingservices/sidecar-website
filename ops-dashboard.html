Pulls completed sales from HAHA's API and fills in both Gross Sales and Cost of Goods automatically, using each product's listed cost. Processing Fees still need your input — HAHA doesn't report those.
Products Missing a Cost
Any product below has no cost set in HAHA's catalogue — its sales sync in with $0 Cost of Goods, which quietly overstates profit until it's fixed. Set the cost on the product in HAHA's Merchant Portal, then re-run a sync to correct past entries.
